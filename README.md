# withyou-legal

WithYou 앱(`com.ongi.withyou`)의 공개 법적 문서. GitHub Pages 로 게시됩니다.

- `privacy.html` — 개인정보 처리방침. Google Play Console 의 처리방침 URL 이 이 파일을 가리킵니다.
- `download.html` — 베타 APK 내려받기 안내(부스 QR 이 가리키는 주소). 버튼은 `releases/latest/download/withyou.apk` 고정 주소라, 새 버전은 **같은 파일명 `withyou.apk` 로 새 Release** 를 만들고 이 페이지의 버전·SHA-256 만 고칩니다.

## 운영 규칙

- **URL 은 바꾸지 않습니다.** Play Console 은 URL 만 저장하므로 같은 URL 에서 내용을 갱신하면 앱 재제출이 필요 없습니다.
- 수집 항목이 늘거나 서버 연동이 생기면 **먼저 이 문서를 개정**하고, 문서 버전·시행일·변경 이력 표를 갱신한 뒤 앱의 동의 문안 버전(`consentDocumentVersion`)을 올립니다. Play Data Safety 양식도 함께 갱신합니다.
- 담당자 성명·정식 명칭 등 잠정값은 PM 확정 후 교체합니다.
