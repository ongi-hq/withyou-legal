How to install

  1. Tap Download. If the browser warns about the file, choose Download anyway.
  2. When the download finishes, tap Open (or open withyou.apk from your notifications).
  3. If your phone asks, allow your browser to install unknown apps, then go back and tap Install.
  4. Samsung phones: if installation is blocked, turn off Auto Blocker in Settings › Security and privacy, install, then turn it on again.
  5. Open WithYou and tap Start as guest.

설치 방법

  1. 내려받기를 누릅니다. 브라우저가 파일을 경고하면 무시하고 다운로드를 고릅니다.
  2. 다 받아지면 열기를 누릅니다 (또는 알림에서 withyou.apk 를 엽니다).
  3. 휴대폰이 물으면 브라우저에 출처를 알 수 없는 앱 설치를 허용하고, 돌아와서 설치를 누릅니다.
  4. 삼성 휴대폰: 설치가 막히면 설정 › 보안 및 개인정보 보호에서 Auto Blocker(보안 위험 자동 차단)를 끄고 설치한 뒤 다시 켭니다.
  5. WithYou 를 열고 게스트로 시작을 누릅니다.
